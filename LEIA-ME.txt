COMO ADICIONAR AS PRÓXIMAS IMAGENS
As sete imagens já estão incluídas no projeto. Para trocar uma oferta futuramente, substitua o arquivo correspondente na pasta images mantendo o mesmo nome e publique novamente no Vercel.

PUBLICAR NO VERCEL
1. Extraia o ZIP.
2. Entre em https://vercel.com e crie um projeto novo.
3. Importe a pasta/repositório do projeto ou arraste os arquivos pelo fluxo de deploy disponível.
4. Não precisa de build command nem framework: é um site estático.
5. Se usar GitHub, envie index.html e a pasta images para o repositório e importe esse repositório no Vercel.
